# Verbesserte Wahlempfehlung durch datenbasierte Optimierung des Smartspider anhand parlamentarischer Abstimmungen

Dieses Repository enthält den Python-Code zur Umsetzung der in der Maturaarbeit beschriebenen Methodik.

Der Code umfasst die Optimierung der Distanzfunktion und die Evaluation des optimierten Modells. Darüber hinaus wurden die verschiedenen Stabilitätsanalysen sowie die Permutations-, Ablations- und Clusteranalysen implementiert. Auch die Erstellung der in der Arbeit verwendeten Abbildungen und Visualisierungen erfolgte mit diesem Code.

Verwendet wurde Python 3.12.10. Die benötigten Python-Pakete sind in der Datei requirements.txt aufgeführt.

## KI-Verzeichnis

Bei der Implementierung des ONNX-Modells wurde KI unterstützend eingesetzt. Auch bei der Erstellung der Abbildungen und der Visualisierungsmöglichkeiten kam KI als unterstützendes Werkzeug zum Einsatz.

Die konkreten Stellen, an denen KI-Unterstützung verwendet wurde, sind durch entsprechende Kommentare im Code gekennzeichnet.
