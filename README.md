# Maturaarbeit-von-Konradin-Buess

Dieses Repository enthält den Code zur Umsetzung der in der Maturaarbeit
beschriebenen Methodik.

Enthalten sind unter anderem die Minimierung und Evaluation des Minimums sowie
die verschiedenen Stabilitätsanalysen. Ausserdem wurden die Permutations- und
Ablationsanalysen sowie das Clustering umgesetzt.

Auch die Erstellung der verwendeten Abbildungen und Darstellungsmöglichkeiten
erfolgte mit diesem Code.

## KI-Verzeichnis

Bei der Umsetzung des ONNX-Modells wurde KI unterstützend eingesetzt.
Auch bei der Erstellung der Abbildungen und Darstellungsmöglichkeiten wurde
KI unterstützend verwendet.

Die konkreten Stellen, an denen KI-Unterstützung verwendet
wurde, sind durch Kommentare im Code gekennzeichnet.
